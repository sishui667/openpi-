# 多颜色方块、长方体、圆柱视觉抓取（2026-10-20）

## 已实现的范围

新增颜色无关的 RGB-D 几何感知与仿真抓取入口。支持已标定水平桌面上**竖直放置、彼此分离、不透明、顶面可见**的简单方块、长方体和圆柱；不是任意日常物品识别，也没有训练/下载新的语义模型权重。

新感知器不按红色或任何颜色分割，RGB 只用于显示。用深度反投影得到机器人坐标中的点，排除桌面，分离连通区域，从顶面估计中心、尺寸、高度和主轴/圆形轮廓。方块是 box 的等尺寸特例。物体尺寸与初始坐标都不作为识别器输入；支持平面高度、桌面边界、相机内外参属于环境标定输入。

现有红方块入口、真人实时双臂跟随以及冻结的抓取 XML 均保留。新入口不更改旧交付版本，不代表完成目标区释放、15 秒 episode 或 BC 训练验收。

## 打开方式

本机桌面有 **“多颜色物体抓取”** 快捷方式。当前默认**不要求预选形状、颜色或尺寸**：点击“打开场景，由相机自动识别”，程序仅在场景布置阶段随机生成一个受支持的几何测试物体；识别器不接收随机选择结果。相机叠加显示 `AUTO cube / box / cylinder` 以及实测尺寸（mm）。方块标签由三条实测尺寸近似相等得到，不来自仿真物体类别。

如需指定测试物体，可展开“自定义仿真测试物体”；其中的形状、颜色、尺寸与位置只用于创建物理世界，不给识别器答案。随机物体仍来自已有三种受支持几何与固定测试尺寸，**不是新增任意物体识别模型，也不是对所有形状都能抓的保证**。

加载后先用鼠标摆放，松开鼠标再按 **空格**，程序才重新拍照规划；摆放阶段物体掉落可按 **R** 恢复，开始抓取后 R 不会传送物体。**Q** 退出。摆放时胸部预览会更新；抓取过程中的胸部/腕部窗口目前是观测阶段快照，不是全程实时视频流。

### 防掉落摆放边界

桌面四侧现有**青色物理挡边**（高 10 mm、厚 6 mm），黄色内框距桌边 8 mm，标示允许物体外形落入的范围。边框不是可达性保证，也不是新的抓取目标。

- **只在摆放阶段**，鼠标编辑的物体完整旋转外形保持在内框内：长方体按完整旋转包围范围计算，圆柱按真实圆柱投影计算，不只限制中心点；拖到桌面下方也会恢复到支撑面以上。这是初始条件编辑辅助，不是执行时的物理约束。
- 正常接触时的小量压入由物理求解器处理，不逐帧瞬移物体来伪造支撑。
- **松开鼠标，再按空格**接受摆放：程序停止残留鼠标扰动，清除物体编辑速度/外力，永久关闭该次测试的摆放修正与 R 复位，再重新拍照。
- **开始抓取后不裁剪坐标、不托住、不传送物体**。只保留真实挡边、碰撞、摩擦和重力；低挡边不能保证强推或高物体倾倒时绝不越过。
- 执行模型和视觉查询模型包含相同挡边，IK 的碰撞检查不能假装挡边不存在；识别器仍不接收目标真实坐标、类型或尺寸。挡边高度低于当前 12 mm 前景阈值，仅在理想仿真深度下验证，不外推真实深度噪声表现。

边界实现只进入新几何识别入口，冻结 XML、旧红方块入口和真人双臂跟随不变。

边界版本验证：相关测试 **42/42 通过**（43.421 秒），含 12 项边界专项；六个固定相机/物理样例 **6/6 通过**，其中三项真实动力学夹取抬升约 70.1、69.9、67.6 mm 且双指接触约 0.8 秒。最终报告 `outputs/generic_objects/benchmark_boundary_final_20261020/summary.json` 的源文件 SHA256 已与当前实现逐项核对。冻结 XML SHA256 未变。低挡边真实碰撞、空桌不误识别和查询模型保留相同挡边均已测试；不代表任意桌边位置都能成功抓取。

`--size` 单位为米；圆柱的前两个值都是直径。`--fixture-pose` 是测试布置，不是抓取目标。默认蓝色圆柱；可选 red/blue/green/yellow/black/white/brown。这些名称不进入颜色阈值。`--check` 运行无窗口物理测试并自动开始；可视模式默认先等待摆放确认，`--auto-start` 才跳过等待。`--perception-only` 只定位，不能据此声称抓取成功。`--report` 指定 JSON 及诊断图片路径。若开始规划后再大幅移动物体，旧方案不会继续夹取，会明确报告“目标可见但已移动，需要重规划”，失败窗口保持显示。

命令行不预选形状的受控测试：`demo_tabletop_objects.py --random-fixture`。随机选择仅在 `setup_fixture()` 内使用；后续检测与 IK 不导入采样器，也不读取测试物体的类别或尺寸。与显式 `--size` 同时使用会报错，避免把隐藏的自定义参数误当生效。

自动几何识别还增加了保守轮廓匹配：顶面既不符合矩形、也不符合近圆轮廓时，不再一律标为 box；圆形拟合增加包围圆填充与轮廓顶点要求，避免把六边形直接当圆柱。这只是可见顶面的几何判断，不保证能区分所有三维物体（例如可见轮廓相近但底部不同的物体）。

## 视觉与规划的信息隔离

胸部 RGB-D 粗定位 → 视觉结果选臂并引导腕部 → 腕部 RGB-D 精定位 → 私有视觉几何模型 → 候选抓取 IK / 采样碰撞检查 → 动力学夹持与抬升。

- 私有查询模型重新编译，目标的类型、尺寸、位置、朝向全部取自观测，不沿用执行仿真里的目标几何。
- 只按机器人关节名复制编码器；不复制目标的自由关节状态，不用渲染器 segmentation ID。
- 长方体只尝试开爪宽度能包住的可见面法向；圆柱尝试四个水平径向轴及两种夹爪朝向，并非搜索所有可行姿态。
- 抓前重新观察同一目标，再求解下降 IK；新残差及采样下降路径重新检查，不能直接执行旧方案的未验证修改。
- 抬升 IK 仍使用私有视觉模型和机器人编码器的夹持跨度。真实物体坐标只在规划冻结后用于误差、抬升和接触评估。
- 不启用焊接，不提高力矩，不传送执行中的物体或机器人来制造抓取成功。

## 尚未支持的情况

未承诺任意可达位置、任意尺寸都能抓取；可见表面不完整、物体相互接触/堆叠、倾倒、非平顶、不规则外形、透明/镜面材质都未完成验证。当前几何检测设置为约 12–200 mm 桌上高度、12–160 mm 顶面尺度；真正能抓还受约束于机械臂姿态与实际夹爪开度。

多个分离物体可输出候选，并要求显式选择或依据上一相机观测保持身份，不默默选择最大的区域。但当前物理演示只布置一个目标，尚未实现多物体杂乱场景避障，也不能把几何上的“圆柱”当成语义上认识“杯子/瓶子”。
