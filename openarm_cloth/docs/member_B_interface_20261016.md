## 2. A→B NPZ 契约

| 字段 | 形状 | 当前处理 |
|---|---|---|
| `joint_angles` | `(F,14)` | 有限关节角，rad；样例为左 7 + 右 7 |
| `target_obs` | `(F,18)` | 有限人体臂方向特征；校验、保留，不把它当世界坐标 |
| `frame_indices` | `(F,)` 整数 | 非负源视频帧号；镜像增广段可能重新编号 |
| `fps` | 可选正有限标量 | 源视频帧率，不自动变成控制频率 |
| `joint_order` | 可选字符串 | `left-first` / `right-first`；数据不能消歧时必须声明 |
| `hand_distance_m` | 可选 `(F,)` | A 的米制拇指尖—食指尖距离；缺失帧填 NaN |

帧数必须一致且非空；NaN/Inf 关节角、不合法帧号、矛盾左右顺序均拒绝。`hand_distance_m` 允许 NaN 表示保持状态，不能为负或 Inf。

样例 `p2a_test.npz` 共 762 行、30 fps，包含原始片段和镜像增广片段；不是连续实时摄像头记录。以 20 Hz 逐行回放耗时约 38.1 秒，等价于时间拉伸，不是声称按原 30 fps 完成。

输出动作布局：`[左臂7, 左指2, 右臂7, 右指2]`，共 18 维。臂关节目标使用 rad，手指位置目标使用 m，开口每指目标范围 `[0,.044]`。PD 最终输出的是限幅力矩，手指是位置伺服，不能混用量纲。

夹爪迟滞：`D<.025 m` 闭合，`D>.045 m` 张开，两边界之间保持。当前样例不含手指数据；演示可用“机器人夹爪到视觉方块距离”代理，但**它不是人的捏合意图**，也不能证明真人控制夹爪。

Python 接入入口：

```python
from member_b_scene import build_scene
from pose2arm_driver import Pose2ArmDriver
model, data = build_scene()
driver = Pose2ArmDriver(model, data, "A_output.npz", arm="right", control_hz=20)
driver.step_frame(0)  # 真正推进 100 × 0.0005 s 的物理步
```

`prepare_frame(i, perceived_center=...)` 只生成目标，不推进物理。实时脚本随后在每个物理步更新同一组 PD 目标；不跳步、不瞬移机器人或方块。

## 3. 固定场景

实际入口是 `member_b_scene.build_scene()`：冻结 XML + `task_workspace.json` 编译前覆写 + 左指伺服修复 + 双臂高位初始化。只直接加载基础 XML 会得到旧桌面，不能作为当前交付场景。

- 实体桌面 24.6×44.6 cm，顶面 40 cm；中心允许摆位区 X `[.35,.51]`、Y `[-.18,.18]` m，周边 4.3 cm 支撑带。
- 方块边长 57.6 mm、质量 0.18 kg；重力 `[0,0,-9.81]` m/s²。
- 物理步长 `.0005 s`，20 Hz 每周期 100 步；原控制器与缓存控制器经 100 步数值等价测试，不通过减少物理步提速。
- 4 对显式指—块接触，`condim=4`、滑动摩擦 1.0、扭转摩擦 .03；无激活物体 weld。关节耦合 equality 是夹爪机构的一部分，不等于把物体粘住。
- 共 6 路仿真相机。`workspace_camera` 是 **90° 正上方单目 RGB**，不是旧文档中的 45°；胸部和腕部 RGB-D 属于自主抓取扩展。
- 绿色目标区中心 `[.43,-.10]` m，半径 3 cm，是无碰撞显示 site。15 秒、抬升 3 cm、距离 2 cm、持续 .5 秒等写入冻结任务契约，**不代表当前 NPZ 已完成搬运并释放**。

精确物理、相机、执行器参数和 60 个资源/运行文件 SHA256 见交付目录 `scene_manifest.json`。包括包装 XML，避免旧临时脚本覆盖相机后未被发现。

## 4. 单目估计适用条件

仅使用当前 RGB、标定相机位姿、已知方块尺寸和桌面平面；不读取物体 qpos/xpos 生成估计。相机外参来自固定安装标定，机器人自身状态用于夹爪位置；这与读取方块真值不同。

跟踪复用上一估计前，会将预测轮廓与**当前帧**掩码比较。IoU≥.97 才复用；否则局部拟合，必要时全局搜索。单元测试证明：只改变隐藏真值、图像不变时估计不变；图像移动时估计跟随变化。

256×192 延迟配置在 5 个位置/角度上误差 2.24–8.94 mm，未达到全部小于 6 mm 的探索性目标。它是接口/性能基线，**不是胸腕精抓取精度保证**。该单目算法假设方块在桌面上，抬起、倾斜或严重遮挡时不能继续宣称 Z 准确。
