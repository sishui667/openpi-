# 双手实时跟随算法优化（2026-10-16）

本轮优化的是 MediaPipe 视觉搜索、绝对腕向映射和诊断记录，不是训练新的 π0.5 或行为克隆权重。没有修改冻结抓取场景、重力、碰撞、PD 增益、电机力矩或关节速度限制。真人视频保持本机文件，不作训练标签上传。

## 根据实际录像定位的问题

使用 `outputs/live_bimanual/20261016_224938_196582/dataset/`。全部有 2373 控制行、1936 个新摄像头观测。前约 52 秒真人未完整进入示范区域，因此不能把全程手部有效比例直接当准确率。

手伸向镜头时前臂的二维投影缩短，但手在画面中变大。原来的裁切框主要按前臂投影定大小，下限 180 像素，会截掉手指。独立抽样检查发现完整入画但 ROI 漏检、全图仍能检出的情况；部分出画或模糊的手仍无法可靠恢复。

绝对转腕原来每帧折回 `[-π,π]` 后直接截到真实 joint5 的约 ±90° 范围。179°→−179° 的小角度跨界会使目标从正限位跳到负限位。真实保存数据中也有单帧约 118°、141° 的掌面估计突变。

## 已修改的算法

1. 手框结合肩宽、图像尺寸与最近完整手部关键点范围；框随最新可用腕点移动，在图像边缘平移而不是裁成小长方形。只使用已捕获的当前或过去数据。
2. 全图双手恢复每 200 ms 与人体、两侧 ROI 推理并行处理同一输入画面，不再等待 ROI 完成后追加串行全图推理。左右手仍按人体腕点一对一关联，不能把同一个候选强行填给两个夹爪。
3. 滤波和 MediaPipe 时间戳按摄像头读取时间计时，不让推理耗时波动改变动作滤波的采样间隔。
4. 绝对腕角连续展开后再执行物理限位。持续可见时不把 >110° 的估计突跳直接当成真实转手；真正丢失、退化或观察间隔超过 100 ms 后，需两次一致新观察确认大角度重识别。正常渐进转动保留。
   绝对 TWIST 控制另外保持手臂参考系的符号连续，避免手臂接近伸直时叉积法向翻转，让爪子的世界朝向跳转约 180°。实际模型测试中，手臂方向只改变约 6.88° 时，修复后的目标朝向也仅改变约 6.88°；随后正常 30° 转腕仍能跟随。
5. 默认分离运行模式增加每侧 `wrist_rejected`、`wrist_limited`、累计拒绝次数与重识别次数；界面区分“掌面估计暂时保持”和“真实关节限位”。每次退出生成的分析报告统计这两类事件，不能将其混为力不够。

## 同输入离线对照

精确重放相同 1055 个原始真人帧，时间范围为第一张保存视频帧后 55.015–114.933 秒。没有打开 USB 摄像头或推进仿真物理。OpenCV/OMP/OpenBLAS 线程设置均为 1。完整记录见 `outputs/optimization/20261016_bimanual/`。

覆盖率的分母使用原记录里该侧人体姿态有效、腕部可见度至少 0.6 且位置在画面内的帧；双手分母要求两侧都满足。没有人工手部真值标注，因此这是检出覆盖率，不是识别准确率。

离线耗时受当前执行环境影响，不是实时摄像头到机器人动作的端到端延迟；中位耗时未改善，不能据此声称每帧 20 Hz 达标。新增检出中包含噪声较大的手部，修订后送往控制的滤波腕角仍测到左 12 次、右 2 次相邻有效观测 >110° 的突变，所以检出覆盖率提高不能替代腕向抗跳变。

实际模型确定性测试中，179°→−179° 的原始腕关节目标跳变从约 180° 降为 0°；这验证角度连续性，不是真人朝向准确率。

离线重放工具 `benchmark_bimanual_vision.py` 可显式指定 `--dataset`、待测 `--module` 和全新的 `--output` 前缀，输出覆盖率、离线推理耗时与腕角跳变统计；它不打开摄像头、不训练、不推进物理，也不调用录像自动清理。

## 复测与限制

控制、录制保留规则及新增回归共 92 项检查：89 项通过，3 项符号链接检查因当前环境不能创建链接而跳过。新增覆盖手框边缘/比例、左右手一对一关联、腕角跨界/持续噪声/重识别、伸肘参考系翻转、正常转腕与诊断事件去重。测试不等于真人视觉识别准确率。

仍用原入口启动：

```powershell
Set-Location 'D:\openpi\openarm_cloth'
& 'D:\openpi\venv_member_ab_live\Scripts\python.exe' -u live_bimanual_human.py --runtime split --save-video
```

建议顺序：双掌正面张开 → 分别握拳 → 双掌相对抬臂 → 缓慢转腕 → 伸手靠近镜头 → 手交叉与短暂遮挡。上半身、双肩、双肘、双腕与手指保持入画。Q 退出后自动保存并分析，本轮离线优化没有创建空白测试去替换现有录像。

相机没有观察到的手指、严重运动模糊、完全遮挡及超出实际关节范围的姿态不能保证复现。交叉手附近原数据曾出现约 99° 的 wrist 目标/实际位置差，可能还涉及物理碰撞或力矩冲突；本轮未增大力矩，也未证明该问题消失。FULL 三自由度手腕模式没有获得本轮完整稳定性验证，默认仍为 TWIST 防塌腕模式。最终同步体验需要新版真人复测。
