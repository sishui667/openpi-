# Pose2Arm 局部避障速查

| | RRT-Connect | 轨迹优化 |
|---|---|---|
| 搜索对象 | 无碰撞关节路径 | 整段离散轨迹 |
| 优势 | 能绕出不同拓扑路线 | 自然兼顾跟踪和平滑 |
| 弱点 | 原始路径折线、随机 | 依赖初值、会陷局部最优 |
| Pose2Arm 用法 | 碰撞片段的逃生路径 | 对窗口轨迹做主规划 |

## 推荐管线

```text
原目标窗口
  → 轨迹优化
  → 失败则 RRT-Connect
  → 捷径化
  → 时间参数化
  → 连续碰撞验证
```

## 硬验收

- 所有采样点与点间扫掠均无碰撞。
- 满足关节限位、速度和加速度限制。
- 规划失败时保持最后安全状态。
